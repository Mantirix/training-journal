Training & Wrestling Journal

Project Overview 
This is a Python-based training and wrestling journal application that allows users to maintain a record of their daily training activities. Some of the features of this journaling application are: 
- Date and training notes 
- Diary entry

The Application Files 
- `main.py`: The main application file containing the main function and interactive menu 
- `diary.py`: Contains functions to save, read, and search the diary entries 
- `training.txt`: The file that stores all training journal entries 
- `wrestling.txt`: The file that stores all wrestling journal entries

 Installation Steps 
1. Download and install Python 3. 
2. Clone or download this repository. 
3. Open the folder in VS studio or in a terminal
4. Type the cmd:  python main.py
5. Follow the instructions to properly manage the journal
